Deprecated all current functions of the ``github`` execution module as well as the ``github`` state module. Use the corresponding functions of the new ``github_org`` and ``github_repo`` modules instead. The ``github`` execution module remains the namespace for functionality that is not tied to a single organization. Notably, ``github.get_user`` looks up organization membership despite its name - its replacement is ``github_org.get_member``. The ``list_members_without_mfa`` function and the per-team MFA enforcement of ``team_present`` are deprecated without replacement - require 2FA organization-wide in the GitHub settings instead
