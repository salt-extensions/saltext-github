The new modules support repositories of any owner. Profiles take an ``owner`` (organization or user; preferred over the legacy ``org_name`` alias), which defaults to the token's user when unset. Repository listing and creation live on the ``github_repo`` module (``list``/``create``), and all of its functions and states as well as all functions of the (now strictly organization-scoped) ``github_org`` module accept a per-call ``owner`` override, so repositories, teams, members and rulesets of foreign organizations can be managed as well. Due to GitHub API limitations, repository creation is only supported for organizations and the authenticated user, private repositories of other users are not listable, tokens without an associated user account (e.g. GitHub App installation tokens) require an explicit ``owner`` and teams always belong to an organization
